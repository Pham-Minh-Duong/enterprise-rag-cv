# Enterprise RAG & Computer Vision Pipeline

Hệ thống AI Production-Ready tích hợp RAG đa ngôn ngữ và Computer Vision, phục vụ qua FastAPI, Triton Inference Server và quản lý bằng Kubernetes/MLflow.

## Tech Stack
- **Backend**: FastAPI, gRPC
- **AI / NLP / CV**: PyTorch, Sentence-Transformers, ONNX Runtime, OpenCV
- **Vector DB**: ChromaDB
- **Serving & MLOps**: Triton Inference Server, MLflow, Docker, Kubernetes (Minikube)
